Introduction

In lab 3, we were tasked with multiplexing a dual seven segment display using the decoder and blinker modules that we developed last week in lab. On top of this, we also developed a keypad scanning module, which will serve as a starting block for lab 3. The seven segment display outputted a hexadecimal value based on the respective input bits, and the keypad scanner outputted LED signals when the correct row and column was toggled.

Design and Testing Methodology

Starting off, I began to design an implementation for the dual seven segment display, based on the decoder module from lab 1. The frequency that the human eye can perceive as a constant light is approximately 60 Hz. With that being said, I decided to use a frequency of 1k Hz to , multiplex the two displays, since this value is well above that number. In order to achieve this frequency, I utilized the onboard HSOSC to generate a 48 MHz clock signal, then set the maximum counter for the MUX to 24000. The calculation to find this number is given by: \(muxmax = \frac{48\text{ MHz}}{2 \times 120\text{ Hz}} = 24,000\)

For the keyboard scanner freqeuncy, I underwent a similar process. Since we wanted all of the columns to be illuminated once with 0.5s, that means each LED would be on for a total of 0.125 s. Given this, each LED would blink twice in one second. In order to achieve this, the keyboard frequency must be 2 Hz, and the maximum counter can be found using: \(maxCount = {48\text{ MHz}} {\times 0.125\text{ s}} = 6,000,000\)

module seven_seg_mux (
    input  logic        clk,
    input  logic        reset,

    input  logic [3:0]  digit0,
    input  logic [3:0]  digit1,

    output logic [6:0]  seg0,
    output logic [6:0]  seg1
);

    // Divider controls the multiplexing rate.
    // Adjust this value for your clock frequency.
    logic [15:0] mux_counter;
    logic        mux_select;

    logic [3:0]  decoder_input;
    logic [6:0]  decoder_output;

    // ------------------------------------------------------------
    // Multiplexing clock
    // ------------------------------------------------------------
    always_ff @(posedge clk or posedge reset) begin
        if (reset) begin
            mux_counter <= '0;
            mux_select  <= 1'b0;
        end
        else begin
            if (mux_counter == 16'hFFFF) begin
                mux_counter <= '0;
                mux_select  <= ~mux_select;
            end
            else begin
                mux_counter <= mux_counter + 1'b1;
            end
        end
    end

    // Select which 4-bit value is presented to the single decoder.
    always_comb begin
        if (mux_select)
            decoder_input = digit1;
        else
            decoder_input = digit0;
    end

    // ------------------------------------------------------------
    // Single 4-bit -> 7-segment decoder
    //
    // Common-anode display:
    //   0 = segment ON
    //   1 = segment OFF
    //
    // Segment order: {a,b,c,d,e,f,g}
    // ------------------------------------------------------------
    always_comb begin
        case (decoder_input)
            4'h0: decoder_output = 7'b0000001;
            4'h1: decoder_output = 7'b1001111;
            4'h2: decoder_output = 7'b0010010;
            4'h3: decoder_output = 7'b0000110;
            4'h4: decoder_output = 7'b1001100;
            4'h5: decoder_output = 7'b0100100;
            4'h6: decoder_output = 7'b0100000;
            4'h7: decoder_output = 7'b0001111;
            4'h8: decoder_output = 7'b0000000;
            4'h9: decoder_output = 7'b0000100;
            4'hA: decoder_output = 7'b0001000;
            4'hB: decoder_output = 7'b1100000;
            4'hC: decoder_output = 7'b0110001;
            4'hD: decoder_output = 7'b1000010;
            4'hE: decoder_output = 7'b0110000;
            4'hF: decoder_output = 7'b0111000;
            default: decoder_output = 7'b1111111;
        endcase
    end

    // ------------------------------------------------------------
    // Store the decoded value for each display.
    //
    // Although the decoder is shared, each output retains its
    // decoded seven-segment pattern after its turn.
    // ------------------------------------------------------------
    always_ff @(posedge clk or posedge reset) begin
        if (reset) begin
            seg0 <= 7'b1111111;
            seg1 <= 7'b1111111;
        end
        else begin
            if (mux_select)
                seg1 <= decoder_output;
            else
                seg0 <= decoder_output;
        end
    end

endmodule

// mux_display.sv
// Time-multiplexes one seven-segment decoder between two 4-bit inputs.
//
// The decoder is active-low for a common-anode seven-segment display.
// The two decoded values are driven onto seg0 and seg1.

module mux_display #(
    parameter WIDTH     = 24,
    parameter MAX_COUNT = 23999
) (
    input  logic       clk,
    input  logic       reset,

    input  logic [3:0] s0,
    input  logic [3:0] s1,

    output logic [6:0] seg0,
    output logic [6:0] seg1
);

    logic select;
    logic [3:0] decoder_input;
    logic [6:0] decoder_output;

    // One instance of the provided seven-segment decoder.
    decoder seg_decoder (
        .s   (decoder_input),
        .seg (decoder_output)
    );

    // Use the provided blinker as a clock divider.
    // blink toggles whenever the counter reaches MAX_COUNT.
    blinker #(
        .WIDTH     (WIDTH),
        .MAX_COUNT (MAX_COUNT)
    ) display_timer (
        .clk   (clk),
        .reset (reset),
        .en    (1'b1),
        .blink (select)
    );

    // Select which 4-bit value is presented to the single decoder.
    always_comb begin
        if (select)
            decoder_input = s1;
        else
            decoder_input = s0;
    end

    // Route the decoder output to the currently selected display.
    //
    // Since the decoder is active-low, the inactive display is
    // turned completely off with 7'b1111111.
    always_comb begin
        if (select) begin
            seg0 = 7'b1111111;
            seg1 = decoder_output;
        end
        else begin
            seg0 = decoder_output;
            seg1 = 7'b1111111;
        end
    end

endmodule
